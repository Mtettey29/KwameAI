# Specs

This directory is the repo's minimal Spec-Driven Development baseline.

For each feature or fix:
1. Create a numbered directory such as `specs/002-some-feature/`.
2. Add `spec.md` for requirements and acceptance criteria.
3. Add `plan.md` for design and implementation decisions.
4. Add `tasks.md` for execution tracking.

The current baseline is intentionally lightweight. It mirrors the core `specify -> plan -> tasks -> implement` flow without introducing extra tooling into the repository yet.
